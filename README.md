# OGGM 源码深度解析 V1.0

《OGGM 源码深度解析》是一部面向中国冰川研究人员的 OGGM 电子书，覆盖 OGGM 基本原理、源码结构、核心物理过程与代码实操。

## 在线阅读

发布到 GitHub Pages 后，可通过仓库的 Pages 地址直接阅读电子书。入口文件为：

- `index.html`

## 面向读者

- 刚入门的冰川方向硕士、博士研究生
- 从冰川生物、冰川化学等交叉方向转向冰川模拟的研究人员
- 熟悉 OGGM、PyGEM、GloGEM 等模型并希望深入源码细节的冰川物理建模人员

## 内容说明

本仓库保存的是静态 HTML 电子书版本。所有章节位于 `chapters/`，样式位于 `css/`。
