# OGGM 源码深度解析 V1.0

《OGGM 源码深度解析》是一部面向中国冰川研究人员的 OGGM 电子书，覆盖 OGGM 基本原理、源码结构、核心物理过程与代码实操。

## 在线阅读

可通过 GitHub Pages 直接阅读电子书：

- https://jonhxu.github.io/oggm-source-code-deep-dive/

## 作者信息

- 作者：徐强强
- 作者所在机构：中国科学院西北生态环境资源研究院 冰冻圈科学与冻土工程全国重点实验室
- 作者简介：作者硕博期间主要从事遥感应用研究。自2022年开始转向冰川变化模拟研究，并在研究过程中持续阅读和使用OGGM，尤其对OGGM源码进行了较为系统和深入的研读。作者最初阅读和使用的版本为OGGM v1.5.3，随后持续跟进至本书基于的OGGM v1.6.3。

## 面向读者

- 刚入门的冰川方向硕士、博士研究生
- 从冰川生物、冰川化学等交叉方向转向冰川模拟的研究人员
- 熟悉 OGGM、PyGEM、GloGEM 等模型并希望深入源码细节的冰川物理建模人员
